# Para - (simple) Personal Finance Manager
## See where your money goes.
Para is a free and open-source personal finance manager designed to help you track your income and expenses without compromising your privacy.

Simple, private, and completely offline.

## Contribute
Para developed on ReactNative/Expo. so just clone and:
1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start the app**

   ```bash
   npx expo start
   ```
